# robo_advisor - LangGraph skeleton

Generated by VG Select: 3A (Automated Agentic Architecture) v0.3.0 for the recommended topology
**Router / classifier dispatch** (`router`). See `ARCHITECTURE.md` for the full
recommendation, the ranked alternatives, the plan and the evidence.

## What is in here

| File | Purpose |
|---|---|
| `app/graph.py` | The LangGraph `StateGraph` wiring the recommended topology |
| `app/agents.py` | Factory for role agents (model per tier, system prompt, tools) |
| `app/config.py` | Model and provider per role (from the catalog selection), fallback, effort, termination limits, budgets |
| `app/tools.py` | Tool stubs for: contribution_limits, create_proposal, get_portfolio, market_data, risk_score, search_methodology, search_policy, search_products, suitability_check, tax_lots - fill in the bodies |
| `app/state.py` | Graph state (`TypedDict`) |
| `main.py` | Runs one request end to end |
| `tests/test_graph.py` | Smoke test: graph compiles, state shape is right |
| `vgselect_profile.json` | The workload profile this skeleton was generated from |

## Run

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # add your ANTHROPIC_API_KEY
python main.py "your first request"
pytest
```

## Fill in (search for TODO)

1. `app/tools.py`: implement each tool; keep descriptions precise - agents choose tools by description.
2. `app/config.py`: confirm model IDs and termination limits; set `MAX_TOOL_CALLS` and `RECURSION_LIMIT` from your latency budget (15s).
3. `app/graph.py`: adjust prompts and the decomposition.
4. Build the ~20-query eval before adding structure; the recommendation assumes you will measure.

## Guardrails already wired

- Recursion/turn limits on every loop (`RECURSION_LIMIT`, `MAX_ITERATIONS`).
- Model per role chosen from the ecosystem catalog against each role's requirements (capability, latency share, context, tools, data class); fallback on another provider where available. Providers in this skeleton: anthropic, openai.
- A verification step before the final answer where the plan calls for it.
- Approval gate hook for irreversible tools (`app/tools.py: requires_approval`).
